# Transaction-History-Outlook-Script

This PowerShell script uses COM objects to read my transaction notification emails from Outlook, extracts the date and amount of each purchase, 
writes this information to an Excel spreadsheet, and adds formulas to get the total amount spent by each month. 

The primary purposes of this project were to try using PowerShell for the first time as well as get a better idea of how much money I spend each month.
